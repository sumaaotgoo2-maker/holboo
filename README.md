# Холбоё — эхний бодит хувилбар

Агуулга: зар харах/хайх, бүртгэл-нэвтрэлт, зар оруулах (шалгалтад орно), Supabase-ийн аюулгүй байдлын дүрэм (RLS).
Админ дэлгэц: /admin (profiles хүснэгтэд role=admin болгосон хэрэглэгчид). Ороогүй: мэдэгдэл илгээх, сум, CV (дараагийн шат).

## Эхлэх алхам
1. supabase.com дээр үнэгүй төсөл нээнэ.
2. Supabase > SQL Editor дээр `supabase/schema.sql`-ийн агуулгыг буулгаж ажиллуулна.
3. Supabase > Project Settings > API хэсгээс URL болон anon key-г хуулна.
4. `.env.local.example`-ийг `.env.local` болгон хуулж, хоёр утгыг бөглөнө.
5. Компьютер дээр: `npm install` ба `npm run dev`, дараа нь localhost:3000 нээнэ.
6. Интернэтэд гаргах: кодоо GitHub-д хуулж, vercel.com дээр Import хийнэ. Vercel-ийн Environment Variables хэсэгт 4-р алхмын хоёр утгыг оруулна.

## Зар батлах
- Админ эрхээр нэвтэрч `/admin` хуудсанд зарыг батлах, татгалзах, хаана.
- Өөрийгөө админ болгох: `profiles` хүснэгтэд өөрийн мөрийн `role`-ийг `admin` болгоно.

## Аюулгүй байдал
- `anon key` нийтэд ил байх зориулалттай, харин `service_role` түлхүүрийг хэзээ ч кодонд бүү оруул.
- Хүн зөвхөн баталсан зарыг харна. Ажил олгогч өөрийн зарыг өөрөө батлах боломжгүй (RLS).
- Нууцлалын бодлого, ашиглалтын нөхцлийг нийтлэхээс өмнө бичих шаардлагатай.
